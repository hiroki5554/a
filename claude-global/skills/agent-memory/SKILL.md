# agent-memory：記憶保存スキル

## 実行手順

1. 会話から保存すべき情報を抽出・整理する
2. 以下のカテゴリに分類する
   - `decisions.md`：意思決定とその理由・背景
   - `preferences.md`：仕事のスタイル・好み・こだわり
   - `facts.md`：事実情報・データ・数値
   - `projects.md`：プロジェクト固有の重要情報
3. `/home/user/business/00_context/memories/{カテゴリファイル}` に追記する
4. 保存した内容をユーザーに報告する

## 保存フォーマット

```markdown
## {TODAY} - {概要タイトル}
{保存内容}
---
```

## カテゴリ別の保存基準

| カテゴリ | 保存するもの | 例 |
|---------|------------|-----|
| decisions.md | 重要な方針決定・判断 | 「A案件は月50万円以上でないと受けない」 |
| preferences.md | 仕事スタイル・好み | 「提案は箇条書き3点以内にまとめてほしい」 |
| facts.md | 数値・固有情報 | 「現在の稼働率は70%」 |
| projects.md | 案件固有の文脈 | 「B案件は来月末が最終期限」 |

## 注意事項
- クライアント名・個人情報は匿名化してから保存する（A社、B案件 等）
- 曖昧な情報は「ユーザーが言ったこと」として明記する
- 既存の記憶と矛盾する場合は、ユーザーに確認してから上書きする
