# daily-schedule：朝の工程表スキル

## 実行手順

1. `/home/user/business/DAILY.md` を読み込み、昨日の未完了タスクを確認する
2. `/home/user/business/02_projects/` を確認し、進行中・期限の近いプロジェクトを把握する
3. `/home/user/business/01_strategy/` に今週の方針メモがあれば確認する
4. 収集した情報をもとに、以下の基準でタスクを分類する
   - 緊急かつ重要：今日中に必ず終わらせる
   - 重要だが緊急でない：時間を確保してじっくり取り組む
   - 緊急だが重要でない：短時間で片付ける
5. 認知負荷の高い作業（思考・判断が必要なもの）を午前中に配置する
6. 15分刻みの工程表を生成する
7. 今日の日付で DAILY.md の「今日の工程表」セクションに書き込む

## 出力フォーマット

```
## {TODAY} 工程表

### 今日のフォーカス（最重要1つ）
- 

### 工程表
| 時間 | タスク | 備考 |
|------|--------|------|
| 09:00 | ... | ... |
| 09:15 | ... | ... |
...

### 今日のタスク一覧
- [ ] （緊急・重要）...
- [ ] （重要）...
- [ ] （緊急）...
```

## 注意事項
- Google Calendar未連携の場合は、ユーザーに「今日の予定はありますか？」と確認してから工程表を作成する
- 工程表は現実的な時間配分にする（詰め込みすぎない）
- 未完了タスクは翌日に自動繰り越しではなく、必ずユーザーに確認してから追加する
