# trend-check：トレンド情報収集スキル

## 実行手順

1. ユーザーからテーマ・調査対象を受け取る（未指定の場合は確認する）
2. **サブエージェントを使って**以下を並列調査する
   - 最新ニュース・業界動向（直近1〜4週間）
   - 主要プレイヤーの動き・競合情報
   - SNS・コミュニティでの話題・反応
   - 数値データ・統計があれば収集
3. 調査結果を以下のフォーマットで整理する
4. `/home/user/business/output/trends/YYYY-MM-DD_{テーマ}.md` として保存する
5. 保存完了をユーザーに報告し、重要ポイントを3点以内で要約して伝える

## 出力フォーマット

```markdown
# トレンドレポート：{テーマ}
調査日：{TODAY}

## サマリー（3行以内）
...

## 主なニュース・動向
1. ...
2. ...
3. ...

## 競合・主要プレイヤーの動き
- ...

## 数値・データ
- ...

## 示唆・考察
...

## 情報ソース
- ...
```

## 注意事項
- 調査はサブエージェントに委託し、メインの会話コンテキストを消費しない
- 情報ソースを必ず記載する
- 推測と事実を明確に区別して記載する
- クライアント名・個人情報は含めない
