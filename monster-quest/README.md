# モンスタークエスト - 草原の冒険 -

ブラウザだけで遊べる、モンスター収集RPGです。
登場するモンスター・技・名前はすべてオリジナルです。

## 遊び方

`index.html` をブラウザ(Chrome / Safari / Edge など)で開くだけで始められます。
インストールは不要です。

## 操作方法

| 操作 | キー |
|---|---|
| 移動 | 矢印キー または WASD |
| 決定・調べる | Z / Enter / Space |
| キャンセル・メニュー | X / Esc |

## ゲームの流れ

1. 最初に相棒モンスターを1体選ぶ(ほのお / みず / くさ)
2. 草むらを歩くと野生モンスターが出現する
3. バトルで弱らせてからキャプチャボールを投げると捕まえられる(手持ちは最大6体)
4. 倒すと経験値が入り、レベルアップで強くなり新しい技を覚える
5. 家の前のピンクのマットに乗ると全回復+ボール補充+セーブ

## マップのヒント

- **南の草むら**: レベル2〜4の弱いモンスターが出る。まずはここで鍛えよう
- **北の草むら**: レベル4〜7の強いモンスターが出る。いわタイプも出現

## タイプ相性(ダメージ倍率)

- ほのお → くさ に強い
- みず → ほのお・いわ に強い
- くさ → みず・いわ に強い
- でんき → みず に強い
- いわ → ほのお に強い

## セーブについて

- メニュー(Xキー)からいつでもセーブ可能
- 回復マットに乗ると自動セーブ
- データはブラウザ内(localStorage)に保存されます
